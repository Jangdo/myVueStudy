Teaming 사용 가이드

프로젝트 팀원 선정 단계

  • 프로젝트에 필요한 역할을 추가하고, 역할에 적합한 팀원은 AI로 빠르고 편리하게 추천받을 수 있습니다.
  • 입찰CP, 계약CP 프로젝트를 제외하고는 선정한 팀원의 소속팀장에게 승인을 받아야 투입이 확정됩니다.

진행상태 변경

  • 역할에 대한 상태 뱃지는 진행 단계에 따라 변경됩니다.
  • 역할만 추가한 ‘미배정' 상태에서 프로젝트에서 투입 기간이 끝난 ‘투입 종료’까지, 역할별로 상태값을 확인하며 ‘To Do’에 해당하는 조치를 취해주세요.
  • 이미 승인받은 ‘투입확정', ‘투입중' 상태의 팀원을 배정 취소하려면 다시 소속팀장의 승인이 필요합니다.
  • ‘배정취소 승인 요청'을 보낸 후 처리 결과를 기다리세요. 승인 될 경우, 해당 팀원은 역할에서 제거되어 ‘미배정’상태가 되며 반려될 경우는 다시 이전의 상태값으로 돌아가 팀장이 작성한 반려 사유를 보여줍니다.
투입 확정 → 취소
투입 중 → 취소

승인 요청 처리

  • 배정 요청 승인 화면의 ‘승인필요' 탭에서 팀원들에 대한 프로젝트 투입 요청을 확인하고, 승인 또는 반려 처리해야합니다.
  • 요청을 반려할 경우, 반려 사유를 필수로 입력해야 하며 작성한 사유는 프로젝트PM에게 전송됩니다.
  • 3일이 경과한 요청건은 자동으로 승인되므로 주의가 필요합니다.

처리 결과 확인

  • 배정 요청 승인 화면의 ‘처리결과'탭에서 해당 연도에 처리한 승인 요청건들의 이력을 확인할 수 있습니다.

팀원 현황 확인

  • 소속팀이 ‘매출귀속조직’으로 설정된 프로젝트 중 프로젝트 시작일이 2주 이내로 임박한 건들을 확인할 수 있습니다.
  • 아직 팀원을 배정하지 못한 ‘미배정'상태의 역할 규모도 파악할 수 있습니다.
  • 자세한 배정 상황은 각 프로젝트의 상세화면으로 들어가서 볼 수 있습니다.
